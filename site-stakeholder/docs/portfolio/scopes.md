# Scopes

**What it is:** the work scope boundaries applicable to products (e.g. Routine, Urgent, Second Opinion, Home Collection).
**Register when:** after the [Issue](../control/issues.md) it answers — each scope names the
Opportunity that justifies it. Issues are registered in [Control](../control/index.md), the
governance PDCA module; use the "+" button on this form's Opportunity field to create one inline.
**Key fields:** Code, Name; `Business Unit *` (multi) → unlocks Opportunity (issues of the
unit's segments, grouped by type); Classification.
