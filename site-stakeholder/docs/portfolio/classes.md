# Classes

**What it is:** a registry classifying scopes (e.g. Thermal).
**Register when:** before Scopes.

**Key fields:**

- **Name / Definition** — what the classification means.
- **Business Units** — the units this class applies to (one or more). On the Scopes form, the Classification picker follows the selected Business Unit: only that unit's classes are offered (no unit selected = every class). A class left without units stays in this registry but out of unit-filtered pickers.
