# Job Family

**What it is:** the HR-standard grouping a function belongs to (e.g. Clinical, Technical) —
people and roles inherit it through their [function](functions.md).
**Register when:** before Functions (each function picks one).
**Key fields:** Name; Description (free text, 2026-09-07 — replaces the old `field`
category label).
