# Skill Levels

**What it is:** proficiency levels applied by competences (Junior/Senior/Expert). Since
2026-09-07 the role carries **no direct level** — the [competence](competence.md) defines
the role + level pair, so one role covers every level instead of near-duplicates per level.
The **rank is not registered here** either — it is the professional's step *inside* a
level, recorded per competence (Skill Rank 1–3 on the Competence form; rank 3 across all
of a level's competences signals readiness to move up).
**Register when:** first in the module.
