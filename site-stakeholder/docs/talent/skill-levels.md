# Skill Levels

**What it is:** proficiency levels required by roles (Junior/Senior/Expert). The **rank is
not registered here** — it is the professional's step *inside* a level, recorded per
competence (Skill Rank 1–3 on the Competence form; rank 3 across all of a level's
competences signals readiness to move up).
**Register when:** first in the module.
