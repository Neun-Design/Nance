# Organization

The organisational context (ISO 9001:2015 §4.1): who you are, where you operate, and how the
company is subdivided. **Everything else in the model hangs off this module — register it first.**

## Entities in this module

Listed in registration order. Each page answers three questions: *what it is*, *when to register one*, and *the key fields* — including which selection unlocks which.

- [**Business Segments**](business-segments.md) — the top-level market segments (e.g. LPT, MPT, DT, SG).
- [**Business Units**](business-units.md) — the operating units inside a segment.
- [**Regions**](regions.md) — geographical groupings (EMEA, Americas, APAC) with the countries they cover.
- [**Departments**](departments.md) — the engineering departments of a unit (e.g. Transformer Repairs Engineering).
- [**Branches**](branches.md) — the physical sites (factories/shops) of the organisation.
- [**Squads**](squads.md) — working groups inside a department (used for forecasting and process assignment).
